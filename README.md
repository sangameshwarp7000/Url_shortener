# 🔗 URL Shortener – Full Stack Application

A full-stack URL Shortener application built using **Angular** and **Node.js with Express.js**. The application allows users to convert long URLs into short, shareable links and manage their shortened URLs through an interactive dashboard.

## 🚀 Features

- 🔗 Shorten long URLs into unique short links
- 📊 Track the number of clicks on shortened URLs
- 📱 Generate QR codes for shortened URLs
- 🔍 Search shortened URLs from the dashboard
- ↕️ Sort URLs based on available details
- 📋 Copy shortened URLs to the clipboard with one click
- 🔄 Real-time interaction between Angular frontend and Node.js backend
- 🌐 RESTful APIs for URL creation and management
